🌱 Habit Tracker

A simple and user-friendly Habit Tracker designed to help users build positive habits, stay consistent, and monitor their daily progress.

📌 About the Project

The Habit Tracker allows users to create and manage their daily habits and track whether they complete them each day.

The goal of this project is to make habit building simple, visual, and motivating by helping users maintain consistency and monitor their progress over time.

✨ Features

➕ Add new habits

✏️ Edit existing habits

🗑️ Delete habits

✅ Mark habits as completed

📅 Track daily habit progress

🔥 Maintain habit streaks

📊 View habit completion progress

💾 Store habit data

📱 Responsive and user-friendly design

🛠️ Technologies Used

HTML5 – Structure of the application

CSS3 – Styling and responsive design

JavaScript – Application logic and functionality
